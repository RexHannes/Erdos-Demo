# Erdős 287 Finite N65/N70 Demo

This folder is a compact, MathOverflow-facing verification demo. It does not prove Erdős #287. It verifies a finite candidate-level anomaly saturation pattern in exported N65 and N70 wide-window datasets.

The live heavy workflows remain in the main `RexHannes/Math-demo` repository under `.github/workflows`. The workflow files copied into `erdosdemo/workflows/` are provenance references only; GitHub Actions does not run workflows from this folder.

## Scope

- Candidate window: `[0.99, 1.01]`
- Main datasets: `N65/P65` and `N70/P70`
- Total anomaly rows in each dataset: `137`
- Normalized N65 and N70 denominator row sets are identical.
- Maximum denominator in both datasets: `36`
- Backbone split in both datasets: `2+31 = 68`, `19+37 = 69`
- Forced cores: every computed `2+31` escape contains `{15,17}`, and every computed `19+37` escape contains `{18,20}`.

The tighter `[0.999, 1.001]` mask-level certificate is a separate artifact in the main work. This folder packages the candidate-level wide-window finite pattern.

## Fast Audit

```bash
python3 erdosdemo/scripts/verify_n65_n70_audit.py
```

Expected output:

```text
N65 rows: 137
N70 rows: 137
N65 not in N70: 0
N70 not in N65: 0
max denominator N65: 36
max denominator N70: 36
computed backbone counts:
  N65 19+37: 69
  N70 19+37: 69
  N65 2+31: 68
  N70 2+31: 68
sentinel:
  N35 rows: 116
  N36 rows: 137
  N70 rows: 137
  N36 vs N70 difference count: 0
errors: 0
PASS
```

This audit reads only the `denominators` column. It independently recomputes exact reciprocal sums, gap bounds, p-adic escape status for `{2,31}` and `{19,37}`, forced cores, maximum denominator, N65/N70 row-set equality, and the N35/N36 sentinel check.

## Template Checks

```bash
python3 erdosdemo/scripts/verify_templates.py
python3 erdosdemo/scripts/verify_n65_templates.py erdosdemo/data/anomalies_N70_candidates.csv
python3 erdosdemo/scripts/verify_dataset_basic.py
python3 erdosdemo/scripts/verify_residue_blocks.py
```

The template scripts verify the four finite N65 template counts:

```text
2+31 + {8,24}:      63
2+31 + {12,20}:      5
19+37 + {22}:       58
19+37 + {21,23}:    11
unclassified:        0
```

The residue script verifies the small p-adic blocks used in the notes.

## Files

- `data/anomalies_N65_candidates.csv`: the finite N65 candidate anomaly dataset.
- `data/anomalies_N70_candidates.csv`: the finite N70 candidate anomaly dataset.
- `data/*.sha256`: SHA256 checksums for the main CSVs.
- `data/sentinel/`: N35 and N36 sentinel CSVs generated locally from the C++ scanner.
- `scripts/verify_n65_n70_audit.py`: independent anti-bug audit using only denominators.
- `scripts/verify_templates.py`: compatibility entrypoint for the N65 template verifier.
- `scripts/verify_n65_templates.py`: verifies row counts, forced cores, and four-template classification.
- `scripts/verify_dataset_basic.py`: verifies dataset integrity and basic arithmetic bounds.
- `scripts/verify_residue_blocks.py`: verifies the small p-adic residue blocks.
- `notes/top_layer_obstruction.md`: short statement of the top-layer obstruction lemma.
- `notes/n65_finite_pattern.md`: finite-pattern summary.
- `workflows/`: copied provenance YAMLs, not live workflows.

## Provenance Caution

The N70 Actions artifact was generated by an N70 workflow and contains N70-specific fields such as the `p67` residue columns. Its merge log reported 137 verified rows but also reported incomplete chunk-status sidecar coverage. For that reason, the public claim here is deliberately narrower: the exported N70 row set is independently checked against the N65 row set and against an N36 sentinel rerun. This is evidence for finite saturation at denominator `36`, not a general theorem.
